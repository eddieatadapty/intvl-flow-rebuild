# INTVL Growth Audit

**Live → https://eddieatadapty.github.io/intvl-flow-rebuild/**

Five ideas to turn more INTVL users into subscribers, each built into a clickable version of INTVL's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Let people plan their first capture before the paywall | +10–20% CR to purchase |
| 02 | Ask how they want to play, then say it back | +8–15% CR to purchase |
| 03 | Sell Pro in the game’s own terms | +5–12% CR to purchase |
| 04 | Show the annual saving and the proof next to the button | +5–10% ARPU, more players on annual |
| 05 | Catch the people who close the paywall | +4–8% CR to purchase |

Every price, rating and feature comes from INTVL's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for INTVL. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
